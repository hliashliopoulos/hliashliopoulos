# Animated Resume

A small personal portfolio for Ilias Iliopoulos, built with HTML, CSS and JavaScript. It includes a short animated résumé and summaries of projects in Java, SQL and Docker. The animation runs in the browser and respects the viewer's reduced-motion setting.

## Run locally

Download or clone the repository and open `animated-resume/index.html` in your browser. Use **Replay animation** to watch the résumé again, or **Explore projects** to jump to the project summaries. The page also has a résumé-only print layout.

## Edit the portfolio

| File | What it controls |
| --- | --- |
| `index.html` | Profile, skills and project descriptions |
| `style.css` | Layout, colors and print styles |
| `resume.js` | Animation timing and replay |

## GitHub Pages

To make the portfolio available online after it is merged, open the repository's **Settings → Pages** and choose **Deploy from a branch**. Select `main` and `/(root)`, then save. The portfolio lives at the published site's `/animated-resume/` path. If the repository already uses a Pages deployment, follow its existing configuration and ensure the folder is included.

[GitHub Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
